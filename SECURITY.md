# Security

Only the current release is supported. Update before reporting a problem.

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/antick/netflix-categories-chrome/security/advisories/new) once the maintainer has enabled it. If that route is unavailable, open a public issue asking for a private contact without including exploit details or user data.

Never attach Netflix credentials, cookies, tokens, personal settings exports, or screenshots containing account information. Include the extension version, Chrome version, affected feature, and a minimal reproduction without real user data.

Maintainer release checks: run the checks in [the submission guide](docs/CHROME_WEB_STORE_SUBMISSION.md), review dependency advisories, and scan reachable Git history and the release ZIP for secrets.
